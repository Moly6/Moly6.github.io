WPF 图片与视频轮播控件 WpfMediaCarousel：功能介绍与使用

发表于2026-11-25|更新于2026-11-25|技术探索WPF
|总字数:1k|阅读时长:3分钟|浏览量:

在 WPF 项目中展示一组图片时，通常需要自己处理当前索引、定时切换、上一张和下一张按钮。加入视频后，还要管理播放、循环、静音和视频加载前的占位画面。为了把这些常用逻辑集中起来，我整理了一个 WPF 图片与视频轮播控件：WpfMediaCarousel。

本文介绍控件的功能、数据准备方式和 XAML 用法。

控件功能

MediaCarouselControl 继承自 WPF Selector，通过 ItemsSource 接收媒体列表。控件会根据当前项的媒体类型展示图片或视频，并提供以下能力：

  • 图片自动轮播，可为单张图片设置独立时长。
  • 上一项、下一项命令和位置指示器。
  • 视频播放、静音、循环播放和视频占位图。
  • 可选的模糊背景、遮罩和占位图淡出动画。
  • StartCarousel、StopCarousel、RestartCarousel 等播放控制方法。

图片和视频都通过 MediaItem 描述。图片项的 Duration 决定自动轮播时的显示时间；视频项播放完成后，如果没有设置循环，控件会继续切换到下一项。

WpfMediaCarousel 还没有发布到 NuGet.org。当前可以从 控件源码仓库 获取源码并将项目添加到解决方案；可运行示例见 WpfMediaCarousel.Demo。NuGet 包正式发布后，上面的安装命令即可直接使用。

控件收到非空媒体列表后会选中第一项。ImageDuration 是图片项的默认显示时长；当 MediaItem.Duration 大于零时，单项时长优先。视频占位图可以通过 MediaItem.PlaceholderSource 单独设置，也可以用控件的 PlaceholderImage 为视频项提供默认占位图。

常用属性

属性 用途
ItemsSource 绑定 MediaItem 列表。
ImageDuration 图片项的默认显示时长。
IsAutoPlay 是否自动切换图片，以及视频结束后是否切换到下一项。选中视频后控件会开始播放。
ShowNavigationButtons 是否显示上一项和下一项按钮。
ShowIndicators 是否显示当前位置指示器。
IsMuted 视频是否静音。
PlaceholderImage 视频的全局默认占位图。
PlaceholderFadeDuration 视频开始播放后占位图淡出的时长。
EnableBlurBackground 是否启用媒体模糊背景。
BlurRadius 模糊背景的半径。
BackgroundOverlayOpacity 背景遮罩透明度，范围为 0 到 1。

控件也公开 NextCommand、PreviousCommand，可以绑定到外部按钮。需要在代码中控制播放时，可以调用 Next()、Previous()、StartCarousel()、StopCarousel() 或 RestartCarousel()。当页面卸载或业务流程结束时，可以调用 CleanupResources() 释放当前视频资源。

使用时需要留意

  1. 本地文件路径要存在。 示例将 Assets 复制到输出目录；若使用 Pack URI 或绝对路径，需要确保 URI 指向有效资源。
  2. 视频播放受系统媒体能力影响。 WPF MediaElement 使用 Windows 媒体组件，目标机器需要支持视频文件对应的格式和编码。
  3. 视频占位图是可选的。 可以在单个 MediaItem 上设置 PlaceholderSource，也可以在控件上设置 PlaceholderImage。前者优先。
  4. 长视频和自动切换。 IsAutoPlay 控制图片定时切换以及视频结束后的自动切换；循环视频会持续播放，直到手动切换或停止。
